# Tutors Academy Homepage Foundation

## Direction
Create a refined light education platform with editorial typography, deep midnight text, restrained teal and warm-gold accents, soft layered depth, and subtle academic geometry. The visual language will feel calm, human, and product-led rather than like a coaching-site template.

## Homepage Structure
- Build a responsive navigation with a clear tutor-finding action and an accessible mobile menu.
- Create the requested 12-section conversion journey: platform-led hero, personal matching value, connected three-step process, interactive tutor finder preview, subject explorer, Classes 1–12 journey, differentiation, parent/student journey, tutor recruitment, clearly labeled testimonial placeholders, FAQ accordion, and closing call-to-action.
- Add a complete professional footer with placeholder contact/social details clearly identified as placeholders.

## Reusable Foundation
- Establish semantic color, typography, spacing, radius, shadow, and motion tokens in the global design system.
- Split the homepage into focused reusable components for navigation, headings, actions, discovery controls, tutor previews, subjects, classes, process steps, testimonials, FAQ, and footer.
- Keep all displayed tutor profiles and testimonials explicitly presented as illustrative previews, ready for real data later.

## Interaction and Motion
- Add purposeful entrance and scroll reveals, connected process motion, restrained floating accents, polished hover/focus feedback, and an animated mobile menu.
- Make the tutor finder controls and class explorer genuinely interactive in the browser without adding backend behavior.
- Respect reduced-motion preferences and preserve keyboard navigation, visible focus, semantic labels, and generous touch targets.

## Responsive and SEO Quality
- Recompose layouts for phones, tablets, laptops, and wide screens rather than shrinking desktop arrangements.
- Add homepage-specific title, description, Open Graph metadata, semantic heading structure, and descriptive links.
- Verify the finished experience at desktop and mobile sizes, test the central interactions, inspect for overflow or overlap, and resolve build/runtime issues.

## Out of Scope
Authentication, payments, dashboards, databases, admin tools, and production matching/search are intentionally excluded from this phase.
